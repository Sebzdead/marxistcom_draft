# CLAUDE.md

## Build & Verify
After CSS/layout changes, rebuild and verify with a preview screenshot before declaring done. When sizing images, check both extremes (avoid cropped AND comically-small results) in a single verification pass.

## Git Workflow
Commit directly to main unless explicitly told to use a branch. Ensure the `gh` CLI is installed/available before attempting PR creation; if missing, push and provide the manual PR link instead of failing silently.
